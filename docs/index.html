fælles eventyr.

Du skal bruge Minecraft Java Edition og den samme modpakke som resten af os. Følg de fire trin her.

01

Åbn CurseForge

Brug CurseForge-appen, vælg Minecraft, og gå til My Modpacks. Serveren bruger Java Edition, ikke Bedrock.

Hent CurseForge
02

Importér den fælles modpakke

Brug modpakkens delingslink eller importkode i CurseForge. Hold dig til den fælles udgave, så mods og versioner passer sammen.

Det nye delingslink er endnu ikke lagt på siden.

Åbn modpakken
03

Start pakken — og serveren

Tryk Play på Create & Magic Lite i CurseForge. Hvis serveren er offline, kan du starte den fra oversigten. Marius' computer skal være tændt og vågen.

04

Tilføj serveren i Minecraft

Vælg Multiplayer → Add Server, skriv et navn, og indsæt adressen herunder. Giv opstarten et øjeblik, hvis status siger »Starter«.

83.88.146.132:25566

En god start

Hvilke teksturer skal jeg vælge?

Vælg Faithful 32x for den lette oplevelse, eller 64x for flere detaljer. Aktivér kun én af dem under Resource Packs.

Hvordan bruger jeg Fullbright?

Standardtasten er G. Shaders kan ændre, hvordan lysstyrke vises, så effekten kan være anderledes med shaders slået til.

Spillet kører tungt

Start med Faithful 32x og MakeUp-pakkens lette profil. Du kan slå shaders fra i videoindstillingerne, uden at ændre serverens mods.

Jeg kan ikke forbinde

Kontrollér, at serveren er online, og at du har skrevet hele adressen inklusive :25566. Brug den fælles modpakke med Forge 47.4.28.

Kan jeg starte en slukket computer?

Nej. Startknappen starter Minecraft-serveren på Marius' computer. Computeren og forbindelsen til panelet skal allerede være i gang.
